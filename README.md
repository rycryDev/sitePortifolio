# 🌌 Personal Portfolio - Arthur Moura

Este é o repositório do meu site de portfólio pessoal. O projeto foi desenvolvido com o objetivo de centralizar e divulgar minha trajetória profissional, acadêmica e projetos, além de servir como um ambiente prático para treinamento e refinamento de habilidades em desenvolvimento web.

O design conta com uma estética voltada para o tema escuro (*dark mode*), destacando-se pela iluminação reativa em tons de roxo e ciano e uma estrutura em grade moderna.

---

## 🚀 Tecnologias Utilizadas

Para a construção e estilização desta página, utilizei tecnologias fundamentais da Web:

* **HTML5:** Estruturação semântica de seções, cartões de tecnologia e links de contato.
* **CSS3 (Custom Properties & Grid/Flexbox):** Estilização responsiva utilizando variáveis CSS, efeitos de iluminação fixa (`radial-gradient`), transições fluidas de escala ao passar o mouse (*hover*) e comportamento de rolagem suave (`smooth scroll`).

> O portfólio também destaca meu ecossistema técnico de atuação, que inclui: **Java**, **.NET (C#)** e **Kotlin**.

---

## 📂 Estrutura do Projeto

A organização dos arquivos segue o padrão de separação de responsabilidades na raiz do projeto:

├── assets/
│   └── images/          # Logotipos das tecnologias (como o logoKOTLIN.svg)
├── scripts/
│   └── scripts.js       # Arquivos de script para comportamentos dinâmicos
├── styles/
│   └── globalStyles.css # Arquivo de estilização central
├── web/
│   └── 404.html         # Página de erro personalizada
├── index.html           # Página principal do portfólio (na raiz)
└── README.md            # Documentação do repositório
